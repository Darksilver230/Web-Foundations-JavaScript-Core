1a. Flexbox
Flexbox is mainly for one-dimensional layouts.

That means you're primarily controlling items along one axis at a time:

Row → left ↔ right
Column → top ↕ bottom
Example

Imagine a navigation bar:

<nav class="navbar">
    <a href="#">Home</a>
    <a href="#">About</a>
    <a href="#">Services</a>
    <a href="#">Contact</a>
</nav>
.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
}

Flexbox solves problems like:

Putting items in a row
Putting items in a column
Centering content
Distributing space between items
Aligning items vertically/horizontally
Making a group of items flexible

1b. CSS Grid

Grid is designed for two-dimensional layouts.

You can control:

Rows
Columns
Both simultaneously

For example:

.container {
    display: grid;
    grid-template-columns: 1fr 1fr 1fr;
    gap: 20px;
}

You could get:

┌────────┐ ┌────────┐ ┌────────┐
│ Card 1 │ │ Card 2 │ │ Card 3 │
└────────┘ └────────┘ └────────┘

┌────────┐ ┌────────┐ ┌────────┐
│ Card 4 │ │ Card 5 │ │ Card 6 │
└────────┘ └────────┘ └────────┘

Grid solves problems like:

Page layouts
Multiple columns and rows
Dashboards
Galleries
Card grids
Complex layouts

1c. min-width vs max-width in media queries

This is extremely important for responsive design.

max-width

Means:

Apply these styles when the screen is this width or smaller.

Example:

@media (max-width: 768px) {
    .navbar {
        flex-direction: column;
    }
}

This means:

0px ───────────────── 768px
       APPLY

So when the viewport is 768px or less, the styles inside the media query apply.

This is commonly used for mobile/tablet breakpoints.

min-width

Means:

Apply these styles when the screen is this width or larger.

Example:

@media (min-width: 769px) {
    .navbar {
        flex-direction: row;
    }
}

This means:

769px ─────────────────────────→
          APPLY

The styles apply when the viewport is 769px or wider.

1d. The difference with an example

Suppose you have:

/* Default */
body {
    font-size: 16px;
}

@media (max-width: 600px) {
    body {
        font-size: 14px;
    }
}

At:

500px → 14px
600px → 14px
700px → 16px
1000px → 16px

Because max-width: 600px means 600px and below.

Now:

@media (min-width: 601px) {
    body {
        font-size: 18px;
    }
}

means:

500px → doesn't apply
600px → doesn't apply
601px → applies
1000px → applies
